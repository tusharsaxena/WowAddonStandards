repo is a **documentation-and-tooling** repo, so documentation-§8's lists apply.

Grading follows the documentation lane, which grades by **what a document causes downstream**:
- **High:** a defect that changes the output of a run somebody has already made.
- **Medium:** a defect that will change the next run.
- **Low:** a defect a reader notices and works around.
- **Info:** an observation.
